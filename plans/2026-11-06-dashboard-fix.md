## 공통 표시 규칙
1. 같은 이름 다른 정의 → 라벨에 출처 '(카페24)'·'(GA4)'.
2. 0 / '—'(데이터 없음) / '추적 끊김' 구분. 비교값 0 이면 증감 대신 '신규'.
3. --down 은 조치가 필요할 때만. 종료·참고는 --muted/--ghost.
4. 화면 문구에 내부 용어(SLOT_MAP·worker.js·entryDirect) 금지. 할 일은 문장 끝.
5. 375px 에선 비교값·체류시간 열 숨김.
메인 탭은 `.section-title .badge` 를 칩으로 쓴다(`.ec-*` 는 ecount-tab.js 전용).
